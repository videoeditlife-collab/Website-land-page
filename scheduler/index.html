Make it post for real

TikTok and Instagram don't allow a web page to post to them directly — a server has to hold your login and talk to their official APIs. Here's the shortest path.

1 · Create the two developer apps (free)

  • TikTok — developers.tiktok.com → new app → add the Content Posting API. Until TikTok audits the app it can only push to your drafts (you tap "post" in the TikTok app). After audit it posts directly.
  • Instagram — the account must be a Professional (Business/Creator) account linked to a Facebook Page. Create a Meta app at developers.facebook.com, add the Instagram Graph API and request the instagram_content_publish permission.

2 · Run the tiny backend

A ~150-line Node/serverless service that this page calls. It does three jobs: hold the OAuth tokens, expose POST /publish, and run a scheduler that fires due posts. This front end already speaks to it — set the URL below and it flips out of simulation mode.

Ask me (Claude) to "build the scheduler backend" and I'll generate it — Netlify Functions + a queue, or a small Express server, your call.

3 · Connect this page

When a URL is set, Post and the scheduler send POST {url}/publish instead of simulating. Clear it to go back to simulation.
